# 부하 테스트 보고서

측정이 끝난 API의 보고서만 올립니다.

- 스크립트와 실행 방법, 환경 만드는 방법은 [README.md](../README.md)에 있습니다. 보고서 폴더 이름은 스크립트 폴더 이름과 같게 만듭니다(`recipes-popular/`, `orders/`, `cart-add/`, `cart-read/` …).
- 모든 숫자는 로컬에서 dev와 같은 서버 구성(앱, 데이터, 검색)에 모니터링 서버를 추가해 맞춘 환경에서 측정한 값입니다. dev·AWS 숫자와 섞지 않고, 같은 조건의 개선 전후 비교에만 씁니다.
- 각 보고서는 대상, 측정 조건(그 API에만 해당하는 데이터와 검색어 등), 부하 조건, 실행 방법, 결과 순서입니다. 캐시 적용 전후 비교가 있는 보고서에만 해석(관찰한 것과 의심되는 원인을 구분)을 붙이고, 다음에 할 것은 개선을 맡은 도메인의 보고서에만 씁니다. 수치는 측정한 값만 적고 측정하지 않은 것은 "미측정"으로 적습니다.

보고서 목록과 핵심 결과는 [README.md의 결과](../README.md#4-결과)에 있습니다.
