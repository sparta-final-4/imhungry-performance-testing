## 1. 질문, 상황, 기준

- 질문: 번개 드롭 알림을 받은 회원 전체가 같은 순간 상품을 검색해도 응답이 늦어지지 않는가.
- 상황: 1,000명이 같은 순간 한 번씩 검색합니다. 로그인 안 함과 로그인 함 두 조건입니다.
- 기준: 회차마다 p95가 0.67초 이하이고 실패가 0건이면 통과입니다.

## 2. 대상과 측정 조건

| 항목 | 내용 |
|---|---|
| API | GET /api/search/products |
| 요청 | `sort=RELEVANCE&page=1&size=16`, 검색어는 대파·두부·계란·된장·김치·삼겹살·밀키트 중 사용자마다 무작위 하나 |
| 로그인 안 함 | 쿠키 없이 1,000명이 보냄 |
| 로그인 함 | 회차마다 준비 단계에서 테스트 회원 1,000명(`loadtest-1`–`loadtest-1000`)이 로그인하고, 가상 사용자 1명이 회원 1명을 맡음 |
| 보내는 방식 | 준비를 마친 뒤 정해 둔 같은 시각에 1,000명이 한 번씩 보냄 |
| 회차 | 조건마다 예열 1회(기록 안 함) 뒤 3회, 회차 사이 10초 |
| 첫 요청 | HTTPS 연결 수립이 들어감(`PREWARM=0`) |

## 5. 분석

- 로그인 안 함의 p95는 2,172–2,512ms로 기준의 3.2–3.7배, 로그인 함은 2,775–3,162ms로 4.1–4.7배입니다(계산).
- 가운데 값은 로그인 안 함 2,415ms, 로그인 함 3,107ms로 로그인 함이 약 1.3배 깁니다(계산). 회차마다 두 조건의 범위가 겹치지 않았습니다.
- 두 조건 모두 회차 사이 p95 편차가 작았습니다(로그인 안 함 340ms, 로그인 함 387ms 차이).

- 가장 빠른 응답은 42–106ms였습니다. 인터넷 왕복 시간이 들어 있는 값입니다.
