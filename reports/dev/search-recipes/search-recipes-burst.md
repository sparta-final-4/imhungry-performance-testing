## 1. 질문, 상황, 기준

- 질문: 번개 드롭 알림을 받은 회원 전체가 같은 순간 레시피를 검색해도 응답이 늦어지지 않는가.
- 상황: 1,000명이 같은 순간 한 번씩 검색합니다. 로그인 안 함과 로그인 함 두 조건입니다.
- 기준: 회차마다 p95가 0.67초 이하이고 실패가 0건이면 통과입니다.

## 5. 분석

- 두 조건 모두 p95가 기준의 3.9배 이상입니다. 로그인 안 함 3회의 가운데 값 3,635ms는 5.4배, 로그인 함의 가운데 값 3,540ms는 5.3배입니다(계산).
- 두 조건의 가운데 값(3,635ms, 3,540ms)은 거의 같습니다. 인기 판매처럼 로그인 함만 느려지는 차이는 없었습니다.
- 로그인 안 함의 1회차에서 1,000건 중 312건(31.2%)이 정상 응답(200)을 받지 못했습니다. 최대 응답 시간이 9.5초였습니다. 상태 코드별 건수는 기록하지 않아 어떤 응답이었는지는 확인하지 않았습니다.
- 로그인 안 함은 예열 8,774ms, 1회차 9,319ms, 2회차 3,635ms, 3회차 2,606ms로 줄어들었습니다. 같은 서버를 회차 사이 10초 간격으로 계속 쓴 결과이며, 줄어든 이유(검색 엔진의 데이터 적재, 오래 쉬던 서버의 예열 등)는 확인하지 않았습니다.
- 로그인 함은 3,450–3,664ms로 회차 사이 편차가 작았습니다.
- 가장 빠른 응답은 50–157ms였습니다. 인터넷 왕복 시간이 들어 있는 값입니다.
- 원인은 확인하지 않았습니다. dev에서는 서버 지표를 보지 않았으므로 검색 엔진, 앱, 연결 수 중 어느 쪽이 느린지 이 보고서의 숫자로는 말할 수 없습니다.
