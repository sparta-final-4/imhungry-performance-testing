## 1. 질문, 상황, 기준

- 질문: 번개 드롭 알림을 받은 회원 전체가 같은 순간 레시피 분류를 불러와도 응답이 늦어지지 않는가.
- 상황: 1,000명이 같은 순간 한 번씩 요청합니다. 로그인 안 함과 로그인 함 두 조건입니다.
- 기준: 회차마다 p95가 0.67초 이하이고 실패가 0건이면 통과입니다.

## 5. 분석

- 같은 API, 같은 캐시인데 로그인 안 함은 p95 193–437ms로 통과했고 로그인 함은 863–1,026ms로 기준의 1.3–1.5배였습니다. 가운데 값은 269ms 대 928ms로 약 3.4배 차이입니다(계산).
- 로그인 함은 p50도 485–696ms로, 요청의 절반이 이미 기준에 가깝습니다. 로그인 안 함은 23–250ms입니다.
- 로그인 안 함의 p50이 회차마다 23ms, 250ms, 27ms로 번갈아 달랐습니다. 이유는 확인하지 않았습니다.
- 로그인 안 함은 p95가 기준 아래인데 최대가 769–1,426ms로, 소수의 요청이 느렸습니다.
- 가장 빠른 응답은 8–17ms였습니다. 인터넷 왕복 시간이 들어 있는 값입니다.
- 로그인 함만 느린 이유는 확인하지 않았습니다. 인기 판매 보고서에서도 같은 현상(로그인 안 함 통과, 로그인 함 미달)이 있었습니다.
