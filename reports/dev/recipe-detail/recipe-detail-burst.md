## 1. 질문, 상황, 기준

- 질문: 번개 드롭 알림을 받은 회원 전체가 같은 순간 레시피 상세를 열어도 응답이 늦어지지 않는가.

## 2. 대상과 측정 조건

| 항목 | 내용 |
|---|---|
| API | GET /api/recipes/{recipeId} |
| 요청 | 준비 단계에서 레시피 목록 1–3쪽(100개씩)의 번호를 받아 사용자마다 무작위 하나를 엶 |

| 첫 요청 | HTTPS 연결 수립이 들어감(`PREWARM=0`) |
