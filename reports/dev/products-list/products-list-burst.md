## 1. 질문, 상황, 기준

- 질문: 번개 드롭 알림을 받은 회원 전체가 같은 순간 상품 목록을 열어도 응답이 늦어지지 않는가.
- 상황: 1,000명이 같은 순간 한 번씩 요청합니다. 로그인 안 함과 로그인 함 두 조건입니다.
- 기준: 회차마다 p95가 0.67초 이하이고 실패가 0건이면 통과입니다.

## 2. 대상과 측정 조건

| 항목 | 내용 |
|---|---|
| API | GET /api/products |
| 요청 | `size=20`, 1쪽 또는 2쪽을 사용자마다 무작위로 엶 |

| 첫 요청 | HTTPS 연결 수립이 들어감(`PREWARM=0`) |
